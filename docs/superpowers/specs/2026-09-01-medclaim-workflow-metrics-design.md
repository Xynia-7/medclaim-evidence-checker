# MedClaim 工作流与产品指标设计

## 目的

补足“模型分数之外的产品价值”：说明 MedClaim 嵌入医学内容审核的具体位置，以及未来如何测量时间、人工复核、危险漏判和证据可审计性。

## 交付形式

新增一份 Markdown 指标卡。它包含 Mermaid 工作流、质量/安全/工作流/运行四类指标、公式、分母、采集字段、实验设计和真实性边界。不建立仪表盘，不生成虚假样本结果。

## 工作流

公开医学主张与来源进入检索和证据关系判断；低置信、证据不足或安全门命中时转人工复核；审核员确认或改写后才进入发布记录，并保留输入、证据版本、模型输出、人工决定与时间戳。

## 指标原则

危险漏判率是安全门，不能被平均分抵消。分类指标与Rubric指标评价回答质量；审核时间、升级率和覆盖率评价工作流价值；格式错误、延迟与费用评价运行稳定性。所有比例明确分子、分母和排除条件。

## 验收

- 指标只使用公开测试病例或未来匿名流程记录；
- 当前已测指标与待测产品假设明确分开；
- 不把模型 Accuracy 当作唯一成功标准；
- 不声称节省时间、临床有效性或真实部署；
- README 和3分钟演示稿可定位到该指标卡。
